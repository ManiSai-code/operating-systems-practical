# Operating Systems Lab

A collection of **Operating Systems laboratory programs and implementations** covering UNIX commands, system calls, CPU scheduling, process synchronization, deadlocks, memory management, page replacement, file allocation, and critical-section problems.

## 📚 Topics Covered

| Exp.   | Topics                                                                                              |
| ------ | --------------------------------------------------------------------------------------------------- |
| **1**  | Basic UNIX Commands and Simulation of `cp`, `ls`, `grep`, etc.                                      |
| **2**  | UNIX System Calls – `fork`, `exec`, `getpid`, `exit`, `wait`, `close`, `stat`, `opendir`, `readdir` |
| **3**  | CPU Scheduling – FCFS, SJF, Priority, Round Robin                                                   |
| **4**  | Semaphores and Monitors                                                                             |
| **5**  | Concurrent Thread Execution using `pthreads`                                                        |
| **6**  | Producer-Consumer Problem and Banker's Algorithm                                                    |
| **7**  | Memory Allocation – First Fit, Best Fit, Worst Fit                                                  |
| **8**  | Page Replacement – FIFO, LRU, LFU                                                                   |
| **9**  | Paging Technique                                                                                    |
| **10** | File Allocation – Sequential, Indexed, Linked                                                       |
| **11** | Synchronization in a Library Management System                                                      |
| **12** | Deadlock Simulation using Printer and Network Resources                                             |
| **13** | CPU Scheduling – LJF and SRJF                                                                       |
| **14** | Peterson's Algorithm for Critical Section                                                           |
